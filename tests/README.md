# Gen Mania — pytest

Запуск из корня репозитория:

```powershell
python -m pytest
```

Или конкретный файл:

```powershell
python -m pytest tests/test_auction_smoke.py -q
```

Тесты:

- используют временную/in-memory SQLite;
- не требуют токена Discord;
- не подключаются к живому боту;
- проверяют аукцион, биржу, банк, серии, сеты, рейды, админ-панель, бэкапы, эмодзи, миграции контента и схемы, баланс экономики, перерождение, баттлпасс, транзакции, почту, экономические эксплойты, гонки, выход из клана, баланс ядра, автосборщик, PvP-лимиты, банк, статусы, навигацию, SafeView, онбординг, пустые состояния, UserSelect, гайд, админ-аудит, PvP-хаб, публичный профиль, шпионаж, браузер кланов, сезон-превью, уведомления, обмен, престиж, магазин, звёздную коллекцию, топы, админ-разделение, вместимость клана, order-book и торговые лимиты, feature flags, accessibility mode, navigation stack, контент-редактор, валидацию контента, баланс питомцев, авто-matching биржи, guard'ы кланов/адвента/кормления, временные статусы, цены улучшений, уникальность новых иконок, отсутствие дублей текста в эмбедах и стартовое приветствие новичка.

`pytest-asyncio` не требуется: async-сценарии запускаются через `asyncio.run()` внутри sync-тестов.
